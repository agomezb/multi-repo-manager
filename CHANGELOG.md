# Changelog

All notable changes to Git Project Explorer are documented in this file.

## 0.1.0

Initial release.

- Automatic detection of Git repositories in the workspace, with configurable search depth and exclude patterns.
- **Explorer** view with one tree per repository, showing branch, uncommitted changes, and ahead/behind counts.
- **Show Only Uncommitted** filter, both globally and per repository.
- Per-repository actions: open in terminal, reveal in file manager, and a **More Actions** menu for pull, push, fetch, checkout, stash, and status.
- **Commands** view to fetch, pull, pull from main/master, push, check out a branch, stash, and stash pop across all repositories.
- **CLI** view to run any command on all or selected repositories, with shortcut chips, command history, and live output per repository.
